:::bottom
- Stage by **G (eGFR) and A (albumin-to-creatinine ratio)** — albuminuria predicts progression.
- Pillars: **ACEi/ARB (max dose) + SGLT2i** (eGFR ≥20, diabetes or not) + **statin** + BP **SBP <120** if tolerated. Diabetes + albuminuria → add **finerenone**, GLP-1 RA.
- Accept a creatinine rise **≤30%** after starting ACEi/ARB.
- **Never** combine ACEi + ARB.
:::

## 🔎 Complications to manage

| Problem | Action |
|---|---|
| Anemia | Iron first (TSAT >20%, ferritin >100); ESA if Hb <10 |
| CKD-MBD | Phosphate binders, vitamin D, cinacalcet |
| Metabolic acidosis | Bicarbonate if HCO₃⁻ <18 |
| Hyperkalemia | Diet, diuretics, patiromer/SZC — keep the ACEi |
| Drug dosing | Metformin (stop <30), DOACs, gabapentin, antibiotics |

## 🧠 ADPKD in 60 seconds

PKD1/PKD2; big cystic kidneys, hypertension, **liver cysts**, **intracranial aneurysms** (MRA if family history), MVP. **Tolvaptan** for rapid progressors.

## 🎓 Board corner

:::board
- Refer to nephrology for eGFR <30, ACR >300, rapid decline (>5 mL/min/year), refractory hypertension, or hereditary disease.
- Avoid gadolinium in eGFR <30 (nephrogenic systemic fibrosis — rare with newer agents).
:::
